# 🇷🇺 Terra — Open-Source Russian Language Trainer

> ⚠️ **Status: Work In Progress (WIP)**  o(≧口≦)o
> It is an active, free, and open-source Russian language learning application in early development (Week 1 milestone). Features, grammar drills, and vocabulary modules are being rolled out iteratively.

---

## 📖 About the Project ヾ(^▽^*)
IT is built to take learners from absolute zero to functional reading and speaking fluency in Russian. Instead of abstract memorization, Terra focuses on demystifying the language's trickiest mechanics early on: phonetic false friends, unpredictable stress marks (*ударе́ние*), and notorious Russian cursive handwriting.

---

## ✨ Current Features (Week 1) q(≧▽≦q)
- **Interactive 33-Letter Alphabet Inspector:** Tap any Cyrillic letter to reveal pronunciation guides, false-friend warnings, and CEFR-tiered (A1/B1/C1) phonetic explanations.
- **Phonetic Category Filters:** Quickly isolate letters by linguistic role:
  - *True Friends* (look and sound like English: А, К, М, О, Т)
  - *False Friends* (look like English, sound different: В, Е, Н, Р, С, У, Х)
  - *Slavic Originals* (unique Cyrillic glyphs: Б, Г, Д, Ж, З, etc.)
  - *Modifiers* (vowel hardener/softeners: Ъ, Ы, Ь)
- **The Cursive Trap Decoder:** Interactive sight-reading tool featuring 12 notorious cursive traps (e.g., *шинши́лла*, *ли́лия*, *защища́ть*). Renders connected handwriting and deconstructs continuous wave loops into color-coded letters on hover/tap.
- **Cursive Tracing Canvas Pad:** Built-in HTML5 `<canvas>` in the inspector drawer equipped with authentic 65° slant guidelines and a letter watermark for freehand stroke practice.
- **Global Toggles:** Instant toggle for stress marks across all Russian text.
